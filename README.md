# Concise
A basic Python script utilizing OpenCV and imutils to read an image and resize it to a specific width and height.

# Feature-Focused Option
Image Resizer Project: Resizes a source image (pandya.jpg) to fixed dimensions (600x400) using OpenCV and the imutils helper library, then saves and displays the result.

# Simple & Direct Option
This project demonstrates simple image manipulation, reading an image with OpenCV and resizing it to 600x400 pixels using the imutils.resize function.
